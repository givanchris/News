Visual Output

Reading the Positioning

The live dashboard above distills these views into a single label. The two charts that do most of the work: where sentiment sits, and where dealers are forced to trade.

Put / Call Ratio Live · trailing 22 sessions

A contrarian gauge, built from real SPY option volume and regenerated with every daily pipeline run. Readings pushing above 1.0 mark hedging/fear spikes that often precede relief; persistent lows flag complacency — see the live SPY/QQQ/IWM figures above for today's exact reading.

Dealer Gamma Exposure Live · by strike

Approximated from real SPY open interest and Black-Scholes gamma across near-term expirations, regenerated with every daily pipeline run. Below the gamma flip dealers are short gamma — hedging amplifies moves and volatility feeds on itself. Above it, hedging dampens moves. Still an approximation, not a disclosed dealer position feed — see Limitations below.

How it works +

// Data Sources

  • Option chains & quotes via yfinance, refreshed weekdays 4:30 PM MT
  • Per-ticker put/call (volume & OI), IV, IV rank/percentile, skew
  • VIX term structure and sector ETF breadth for market context
  • SPY put/call history accumulates daily to redraw the trailing-22-session chart automatically

// Methodology

  • Metrics normalized to rank/percentile so tickers are comparable
  • Weighted blend of P/C, IV rank, skew, and unusual volume → one sentiment score
  • Gamma exposure: Black-Scholes gamma per strike × open interest, summed across near-term expirations through the next monthly
  • Score bucketed into a label: bullish / neutral / bearish

// Assumptions

  • End-of-day snapshot, not real-time streaming
  • Dealers assumed net short puts / long calls for the GEX sign convention
  • Skew measured at fixed deltas across the front expiries

// Limitations

Retail/free option data is noisy and can lag; GEX is an approximation without dealer-position disclosure — not a real position feed, regardless of how current the underlying open interest is. Sentiment is a contrarian context tool, not a trade signal.
