How it works +

// Data Sources

  • FOMC statement archive (federalreserve.gov), read side-by-side
  • Same-day yield moves from the Treasury.gov H.15 series
  • Decisions, target ranges, SEP dots, and dissents logged by hand

// Methodology

  • Each statement diffed against the prior: phrases tagged added / removed / changed / retained
  • Stance reflects the statement + SEP composite, not just the decision
  • Yield reaction measured 2pm statement → 3pm close (2Y, 10Y, 2s10s)
  • Phrases ranked by how consistently they preceded the next move

// Assumptions

  • Same-day move attributes the reaction to the statement (not later data)
  • Curated inflection meetings, not every meeting in the cycle
  • Implied-probability and curve figures here are representative, not a live feed

// Limitations

Language analysis is interpretive, and small samples mean "predictive" phrases are suggestive, not statistically proven. The intraday window can capture coincident data surprises. This is a research log, curated by hand — not an automated signal.
